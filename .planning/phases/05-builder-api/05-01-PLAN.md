**1. Add BuilderError and BuilderErrors to `src/error.rs`:**

Add a `BuilderError` enum AFTER the existing `Error` enum and `Result` type alias. Include these variants:
- `DuplicateStep(String)` -- step name used more than once
- `MissingStep { edge_endpoint: String }` -- edge references undefined step
- `CycleDetected(String)` -- cycle involving named step
- `DisconnectedStep(String)` -- step with no edges in multi-step workflow
- `EmptyWorkflow` -- no steps added

Implement `std::fmt::Display` for `BuilderError` with clear error messages matching the research doc's examples. Implement `std::error::Error` for `BuilderError`.

Add a `BuilderErrors` wrapper struct containing `pub errors: Vec<BuilderError>`. Implement `Display` for `BuilderErrors` that joins all error messages with "; ". Implement `std::error::Error` for `BuilderErrors`. Implement `From<BuilderErrors> for Error` that converts to `Error::InvalidWorkflow` by joining the error messages.

**2. Create `src/workflow/builder.rs`:**

Create the `WorkflowBuilder` struct with two private fields:
- `steps: Vec<(String, Step)>`
- `edges: Vec<(String, String)>`

Implement these methods, ALL using consuming self (move semantics) -- consistent with `ModelOptions::with_temperature` pattern:

- `pub fn new() -> Self` -- creates empty builder
- `pub fn step(mut self, name: impl Into<String>, step: Step) -> Self` -- adds a raw Step
- `pub fn transform_step(self, name: impl Into<String>, transform: impl Fn(&StepInput) -> Result<Value> + Send + Sync + 'static) -> Self` -- convenience that wraps in `Step::Transform { transform: Box::new(transform) }` and delegates to `self.step()`
- `pub fn llm_step(self, name: impl Into<String>, model: Box<dyn Model>, prompt_builder: impl Fn(&StepInput) -> String + Send + Sync + 'static) -> Self` -- convenience that wraps in `Step::Llm` with `tools: None, options: ModelOptions::default()` and delegates to `self.step()`
- `pub fn llm_step_with_tools(self, name: impl Into<String>, model: Box<dyn Model>, prompt_builder: impl Fn(&StepInput) -> String + Send + Sync + 'static, tools: ToolRegistry, options: ModelOptions) -> Self` -- full LLM step with tools and options
- `pub fn edge(mut self, from: impl Into<String>, to: impl Into<String>) -> Self` -- adds edge with (from, to) convention matching Workflow::new
- `pub fn chain(mut self, steps: &[&str]) -> Self` -- uses `windows(2)` to create edges for linear sequences

Add a stub `pub fn build(self) -> std::result::Result<Workflow, BuilderErrors>` that simply delegates to `Workflow::new(self.steps, self.edges)` and wraps any error in a single-element `BuilderErrors`. This is a placeholder -- Plan 02 replaces it with proper validation logic. NOTE: Use `std::result::Result` explicitly (not the crate's `Result<T>` alias which has `Error` as the error type).
