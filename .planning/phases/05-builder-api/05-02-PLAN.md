  <name>Task 1: Implement build() validation with error collection</name>
  <files>src/workflow/builder.rs</files>
  <action>
Replace the stub `build()` method in `src/workflow/builder.rs` with full validation logic. The method must:

**1. Empty workflow check:**
If `self.steps` is empty, return `Err(BuilderErrors { errors: vec![BuilderError::EmptyWorkflow] })` immediately. No further validation is needed.

**2. Duplicate step detection:**
Iterate `self.steps` and collect any names that appear more than once. Use a `HashSet<&str>` to track seen names. For each duplicate, push `BuilderError::DuplicateStep(name.clone())` into the errors vec.

**3. Build the petgraph DiGraph:**
Create a `DiGraph<String, ()>` and add all step names as nodes (using the first occurrence if duplicates exist, to allow further validation). Store a `HashMap<String, NodeIndex>` mapping step names to node indices.

**4. Missing step detection on edges:**
For each edge `(from, to)` in `self.edges`, check if both `from` and `to` exist in the step name set. For each missing endpoint, push `BuilderError::MissingStep { edge_endpoint: name.clone() }`. Only add the edge to the graph if BOTH endpoints are valid (to avoid panics in petgraph).

**5. Cycle detection:**
Run `petgraph::algo::toposort(&graph, None)`. If it returns `Err(cycle)`, push `BuilderError::CycleDetected(graph[cycle.node_id()].clone())`.

**6. Disconnected step detection (LOCKED USER REQUIREMENT):**
Only run this check if `self.steps.len() > 1` (single-step workflows are exempt). For each node in the graph, check if it has ZERO incoming neighbors AND ZERO outgoing neighbors using `graph.neighbors_directed(idx, Direction::Incoming).count() == 0 && graph.neighbors_directed(idx, Direction::Outgoing).count() == 0`. For each such node, push `BuilderError::DisconnectedStep(name.clone())`.

**7. Return result:**
If the errors vec is non-empty, return `Err(BuilderErrors { errors })`. Otherwise, construct the workflow by calling `Workflow::new(self.steps, self.edges)` and map any error (which should not occur since all checks passed) into a single-element `BuilderErrors`.

**Required imports to add at top of builder.rs:**
```rust
use std::collections::{HashMap, HashSet};
use petgraph::algo::toposort;
use petgraph::graph::{DiGraph, NodeIndex};
use petgraph::Direction;
```

**Important details:**
- Edge convention: `(from, to)` means "from must complete before to" -- matches Workflow::new exactly.
- Disconnected check: use AND (no incoming AND no outgoing), NOT OR. Root steps (no incoming) and leaf steps (no outgoing) are normal.
- Error collection: run ALL checks even if earlier ones found errors. The only exception is empty workflow (return immediately since there is nothing else to validate).
- Avoid duplicate errors: when a step name appears in multiple edges, only report it as MissingStep once. Use a `HashSet` to track already-reported missing step names.
