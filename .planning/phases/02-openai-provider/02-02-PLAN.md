**Conversion functions (private, module-level):**

- `fn to_chat_message(msg: &Message) -> ChatMessage` -- Converts internal Message to wire ChatMessage. Match on msg.role:
  - Role::System -> ChatMessage::System { content }
  - Role::User -> ChatMessage::User { content }
  - Role::Assistant -> ChatMessage::Assistant { content (None if empty, Some otherwise), tool_calls (convert Vec<ToolCall> to Vec<ToolCallWire> if present) }
  - Role::Tool -> ChatMessage::Tool { content, tool_call_id (from msg.tool_call_id, unwrap_or_default) }

- `fn to_chat_tool(tool: &ToolDefinition) -> ChatTool` -- Wraps a flat ToolDefinition into OpenAI's nested `{"type": "function", "function": {...}}` format. Sets tool_type to "function".

- `fn parse_response(response: ChatCompletionResponse) -> Result<ModelResponse>` -- Extracts the first choice from response.choices. Returns Error::UnexpectedResponse if choices is empty.

  From the first choice's message (ResponseMessage):

  **If tool_calls is Some and non-empty:** Convert each ToolCallWire to the internal ToolCall type using explicit field mapping:
    - `tc.id` -> `ToolCall { id: tc.id }`
    - `tc.function.name` -> `ToolCall { name: tc.function.name }`
    - `tc.function.arguments` -> `ToolCall { arguments: tc.function.arguments }`

  This flattens the nested OpenAI structure (`ToolCallWire.function.name`) into the flat internal structure (`ToolCall.name`). Return `ModelResponse::ToolCalls(tool_calls)`.

  **Otherwise if content is Some:** Return `ModelResponse::Text(content)`.

  **Otherwise:** Return `Error::UnexpectedResponse` (neither content nor tool_calls present).

**Private send method:**

- `async fn send_request(&self, request: &ChatCompletionRequest) -> Result<ModelResponse>` -- Constructs URL as `format!("{}/chat/completions", self.base_url)` where base_url defaults to `https://api.openai.com/v1` (set in constructor). This produces the full endpoint URL `https://api.openai.com/v1/chat/completions`. Sets headers: Authorization (Bearer token), Content-Type (application/json). Sends via self.client.post(url).json(request).send().await.

  Error handling pattern (CRITICAL -- do NOT use error_for_status):
  1. Get response, let reqwest::Error propagate via ? for network failures (becomes Error::Api via #[from])
  2. Read status BEFORE consuming body
  3. If status is not success: read body as text, try to parse as ApiErrorResponse to extract structured message, fall back to raw body text. Return Error::ApiResponse { status, message }
  4. If status is success: parse body as ChatCompletionResponse via response.json(). Deserialization errors propagate via ? (becomes Error::ResponseParse via #[from])
  5. Call parse_response() on the deserialized response
