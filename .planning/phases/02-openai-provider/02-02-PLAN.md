**OpenAiProvider struct (public):**
```rust
pub struct OpenAiProvider {
    client: reqwest::Client,
    api_key: String,
    base_url: String,
    model: String,
}
```

Four fields: client (connection-pooling HTTP client), api_key, base_url (defaults to "https://api.openai.com/v1"), model (e.g., "gpt-4o").

**Constructors:**

- `pub fn new(api_key: impl Into<String>, model: impl Into<String>) -> Self` -- Creates provider with default base URL. Instantiates one reqwest::Client for connection reuse.

- `pub fn from_env(model: impl Into<String>) -> Result<Self>` -- Reads OPENAI_API_KEY from environment. Returns `Error::Config("OPENAI_API_KEY environment variable not set")` if missing.

- `pub fn with_base_url(mut self, base_url: impl Into<String>) -> Self` -- Builder method for custom endpoints (Azure OpenAI, proxies). Returns Self for chaining.

**Conversion functions (private, module-level):**

- `fn to_chat_message(msg: &Message) -> ChatMessage` -- Converts internal Message to wire ChatMessage. Match on msg.role:
  - Role::System -> ChatMessage::System { content }
  - Role::User -> ChatMessage::User { content }
  - Role::Assistant -> ChatMessage::Assistant { content (None if empty, Some otherwise), tool_calls (convert Vec<ToolCall> to Vec<ToolCallWire> if present) }
  - Role::Tool -> ChatMessage::Tool { content, tool_call_id (from msg.tool_call_id, unwrap_or_default) }

- `fn to_chat_tool(tool: &ToolDefinition) -> ChatTool` -- Wraps a flat ToolDefinition into OpenAI's nested `{"type": "function", "function": {...}}` format. Sets tool_type to "function".

- `fn parse_response(response: ChatCompletionResponse) -> Result<ModelResponse>` -- Extracts the first choice. If tool_calls present and non-empty, converts to Vec<ToolCall> (flattening ToolCallWire -> ToolCall) and returns ModelResponse::ToolCalls. Otherwise extracts content text and returns ModelResponse::Text. Returns Error::UnexpectedResponse if no choices, or if neither content nor tool_calls present.

**Private send method:**

- `async fn send_request(&self, request: &ChatCompletionRequest) -> Result<ModelResponse>` -- Builds the POST request to `{base_url}/chat/completions`. Sets headers: Authorization (Bearer token), Content-Type (application/json). Sends via self.client.post().json(request).send().await.

  Error handling pattern (CRITICAL -- do NOT use error_for_status):
  1. Get response, let reqwest::Error propagate via ? for network failures (becomes Error::Api via #[from])
  2. Read status BEFORE consuming body
  3. If status is not success: read body as text, try to parse as ApiErrorResponse to extract structured message, fall back to raw body text. Return Error::ApiResponse { status, message }
  4. If status is success: parse body as ChatCompletionResponse via response.json(). Deserialization errors propagate via ? (becomes Error::ResponseParse via #[from])
  5. Call parse_response() on the deserialized response
