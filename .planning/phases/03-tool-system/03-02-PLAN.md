**dispatch method:**

```rust
/// Execute a single tool call and return the result as a Message.
///
/// Looks up the tool by name, parses the JSON arguments string into
/// a serde_json::Value, calls the tool's execute method, and wraps
/// the result in a Message::tool_result with the correct tool_call_id.
///
/// # Errors
///
/// - `Error::ToolNotFound` if no tool with the given name is registered
/// - `Error::ResponseParse` if the arguments string is not valid JSON
/// - `Error::ToolExecutionFailed` if the tool's execute method fails
pub async fn dispatch(&self, tool_call: &ToolCall) -> Result<Message> {
```

Implementation steps:
1. Look up tool by `tool_call.name` using `self.tools.get()`. If not found, return `Err(Error::ToolNotFound(tool_call.name.clone()))`.
2. Parse `tool_call.arguments` from JSON string to `serde_json::Value` using `serde_json::from_str()`. The `#[from] serde_json::Error` on `Error::ResponseParse` handles conversion automatically via `?`.
3. Call `tool.execute(args).await`. If it returns an error, map it to `Error::ToolExecutionFailed { name: tool_call.name.clone(), message: err.to_string() }` using `.map_err()`.
4. Build and return `Message::tool_result(tool_call.id.clone(), tool_call.name.clone(), result)`.

**dispatch_all method:**

```rust
/// Execute multiple tool calls sequentially and return results as Messages.
///
/// Processes tool calls one at a time, in order. Stops immediately on the
/// first error (fail-fast behavior). Does not execute remaining tool calls
/// after a failure.
///
/// # Errors
///
/// Returns the first error encountered. Any tool calls after the failing
/// one are not executed.
pub async fn dispatch_all(&self, tool_calls: &[ToolCall]) -> Result<Vec<Message>> {
```

Implementation: iterate over tool_calls, call `self.dispatch(tc).await?` for each, collect into a Vec. The `?` operator provides fail-fast behavior automatically.

Import the necessary types at the top of `src/tool.rs`:
- `use crate::types::ToolCall;` (if not already imported)
- `use crate::message::Message;` (if not already imported)

Note on error mapping for tool execution: When `tool.execute()` returns `Err(e)`, we need to wrap it in `ToolExecutionFailed`. However, `e` is already an `Error` type from the framework. Use `map_err` to convert:
```rust
let result = tool.execute(args).await.map_err(|e| Error::ToolExecutionFailed {
    name: tool_call.name.clone(),
    message: e.to_string(),
})?;
```

This wraps whatever error the tool produced (it could be any Error variant) into ToolExecutionFailed with the tool name for context.

mod tests {

    /// A simple test tool that echoes its input back.

    impl Tool for EchoTool {
        fn name(&self) -> &str { "echo" }
        fn description(&self) -> &str { "Echoes the input message back" }
        fn parameters(&self) -> serde_json::Value {
            serde_json::json!({
                "type": "object",
                "properties": {
                    "message": { "type": "string" }
                },
                "required": ["message"]
            })
        }
        async fn execute(&self, args: serde_json::Value) -> Result<String> {
            let message = args["message"].as_str().unwrap_or("no message");
            Ok(format!("echo: {}", message))
        }
    }

    /// A tool that always fails, for testing error handling.
    struct FailingTool;

    #[async_trait]
    impl Tool for FailingTool {
        fn name(&self) -> &str { "failing" }
        fn description(&self) -> &str { "Always fails" }
        fn parameters(&self) -> serde_json::Value {
            serde_json::json!({"type": "object"})
        }
        async fn execute(&self, _args: serde_json::Value) -> Result<String> {
            Err(Error::ToolExecutionFailed {
                name: "failing".into(),
                message: "intentional failure".into(),

        }
    }
